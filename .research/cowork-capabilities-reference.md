# Microsoft 365 Copilot Cowork: capability reference

> **Use this note when generating or revising Copilot Cowork exercises.** It is a quick reference for what Cowork can do. Recheck the official Microsoft Learn page before publishing an exercise, because product behavior, availability, and labels can change.

## Source and validation

- **Official source:** [Copilot Cowork overview](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/)
- **Source last updated by Microsoft:** 2026-06-16
- **Validated for this workshop:** 2026-06-25

## What Cowork can do

Cowork can complete work across Microsoft 365 on the user's behalf. It shows its steps in the conversation and asks for approval before important actions are carried out.

### Communication

- Draft, reply to, forward, and send email.
- Post updates in Teams channels or send messages in individual and group chats.
- Prepare and email HTML newsletters.
- Organize email by filing, deleting, or replying inline.
- Prepare stakeholder communications, including status updates, announcements, and follow-ups.

### Documents and files

- Create Word documents, Excel workbooks, PowerPoint presentations, and PDFs.
- Edit or refine files that are shared in the conversation.
- Find relevant organizational content through Work IQ.
- Create folders in SharePoint and OneDrive.
- Organize existing files into new or existing folders.

### Calendar and meetings

- Create meetings from natural-language requests and add attendees.
- Manage calendar events, including moving events and declining conflicting meetings with an optional note to the organizer.
- Surface meeting intelligence to support preparation.
- Provide a daily briefing of upcoming work.

### Research and search

- Search organizational documents, messages, and information.
- Produce deep-research reports that synthesize information from multiple sources.
- Browse SharePoint and OneDrive, then select files to use in the task.

### Automation

- Schedule prompts so recurring work can run automatically.

## Exercise-generation and revision guidance

- Use the capability groups above to choose exercises that reflect actual Cowork tasks.
- For actions that send, post, schedule, delete, or otherwise change work data, teach learners to review and approve the action before it happens.
- Keep exercise steps outcome-focused. Avoid treating a particular UI label or flow as permanent unless it has been rechecked in the official documentation on the day of revision.
- Validate prerequisites, access, licensing, and tenant-specific limitations against the official Microsoft guidance separately; this note is a capability reference, not a complete availability guide.
