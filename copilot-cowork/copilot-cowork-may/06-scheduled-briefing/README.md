# Exercise 06 (Optional): ตั้ง Scheduled Briefing

🔑 ทำข้อนี้เมื่อเมนู **Scheduled** ปรากฏใน tenant และ Facilitator อนุมัติให้ทดลองแล้ว

Cowork สามารถตั้ง prompt ให้ทำงานตามเวลาได้ ในแบบฝึกหัด optional นี้ เราจะตั้ง briefing ที่ปลอดภัยสำหรับตัวเอง ตรวจสอบรายการใน Scheduled แล้ว pause/delete ทันที

> **ห้าม** ตั้งงานที่ส่งอีเมล โพสต์ Teams หรือแก้ไขไฟล์โดยอัตโนมัติใน workshop นี้

---

## Feature 1: ตั้งงานสรุปแบบตั้งเวลา

1. เปิด Cowork แล้วเริ่ม task ใหม่สำหรับแบบฝึกหัดนี้

2. ส่ง Prompt ตัวอย่างด้านล่าง โดยปรับเวลาให้เหมาะกับ timezone ของบัญชีทดสอบ:

   ```
   ทุกวันทำงานเวลา 08:30 สร้าง briefing สำหรับฉัน โดยสรุป agenda ในปฏิทินวันนี้และ task ที่ต้องติดตามจาก Cowork tasks
   แสดงผลใน Cowork เท่านั้น ห้ามส่งอีเมล โพสต์ข้อความ หรือสร้างนัดหมาย
   ```

3. ตรวจรายละเอียด schedule และ timezone ที่ Cowork เสนอ หากมี approval card ให้ตรวจ preview ก่อนดำเนินการ

---

## Feature 2: ตรวจสอบและหยุด Scheduled task

1. เปิด **Scheduled** จากหน้า Cowork หรือจากส่วน Schedule ใน Side panel

2. ตรวจว่ามีชื่อ task, เวลา และความถี่ตามที่ขอ

3. เลือก **Pause** เพื่อหยุด task ก่อนเวลาที่จะทำงานจริง

4. ถ้าไม่ต้องการเก็บไว้ ให้เลือก **Delete** หลัง Facilitator ยืนยัน

5. บอก Facilitator หากไม่เห็น Scheduled; ความสามารถนี้อาจถูกปิดใน tenant และให้ข้าม exercise นี้ได้

---

## สรุป

คุณได้เรียนรู้วิธีสร้าง ตรวจสอบ และควบคุมงานที่ตั้งเวลา โดยยังเก็บขอบเขตการทดลองไว้ภายในบัญชีทดสอบ
